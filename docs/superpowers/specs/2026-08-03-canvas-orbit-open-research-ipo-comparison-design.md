## 1. 首页 Canvas 决策轨道

### 视觉结构

- 新增独立的 `DecisionOrbit` 客户端组件。
- 轨道、光晕、粒子、方形决策点和移动标签由 Canvas 绘制。
- 中央“三层叠片 + 决策 + 多维验证”使用 DOM 覆盖层，保证文字和图标在不同像素密度下清晰。
- 五个决策点为：公司、生意、估值、技术、风控。
- 每个决策点拥有独立的椭圆长短轴、倾斜角、初始相位、速度和方向，形成类似太阳系小行星公转的层次感。

### 动画模型

- 使用 `requestAnimationFrame` 驱动，基于真实时间差计算角度，不依赖固定帧率。
- 每条轨道的移动点按椭圆参数方程计算，再按轨道倾角旋转。
- 标签始终保持水平，不随轨道倾角旋转。
- 鼠标进入动效区域后整体速度降至正常速度的 35%，移出后平滑恢复。
- 页面切换到后台、组件离开视口或尺寸为零时暂停动画，恢复后继续。
- 使用 `ResizeObserver` 适配桌面、平板和移动端；根据 `devicePixelRatio` 提升清晰度并限制最大像素比，避免高分屏过度消耗。
- `prefers-reduced-motion: reduce` 时只绘制一帧静态构图，不启动循环动画。

### 无障碍与降级

- Canvas 提供完整中文 `aria-label`，说明五项研究维度围绕决策中心运行。
- Canvas 内提供回退文本，无法绘制时仍可理解研究模型。
- 动画不承担导航功能，不引入点击热点或键盘陷阱。
