# 首页数字递增与全站滚动浮现设计

日期：2026-08-04  
状态：已确认（用户明确要求按推荐方案直接处理，不再询问）

## 目标

参考 Sober 期权工作室首页的交互节奏，为 803见势研究增加两类一次性入场动效：

1. 首页成果指标进入视口后，从 0 平滑递增到最终值。
2. 全站主内容在向下滚动时按区块和卡片逐步浮现。

动效用于建立浏览节奏与层次，不改变任何研究数据、导航行为或页面信息架构。

## 参考结论

- 参考站点的成果数字在未进入视口时显示 0，进入视口后递增到目标值。
- 参考站点的下方内容使用一次性浮现，不在用户来回滚动时反复隐藏和播放。
- 本项目复用这一触发逻辑与视觉节奏，但使用自身的深色研究平台样式，不复制参考站点代码。

## 首页数字递增

适用范围仅为 `WHY 803` 证明矩阵中的四项成果指标：

- 10 年持续深耕 A 股研究
- 300+ 位累计服务学员
- 2 套持续运行规则策略
- 1200 天社群活跃更新

不适用于日期、时间、价格、股票代码、百分比、风险分、章节编号或 IPO 数据，避免让实时和财务信息产生不必要的跳动。

### 行为

- 数字所在证明矩阵第一次进入视口时开始计数。
- 初始可见数字为 0，使用由快到慢的缓动在约 1.4 秒内到达目标。
- 四个指标使用约 90 毫秒错峰，形成连续但不拖沓的节奏。
- `+` 与单位独立渲染，计数过程中保持稳定。
- 每个数字每次页面加载只播放一次；滚出再滚回不重播。
- 服务端 HTML 保留最终语义值，确保无 JavaScript、SEO 与辅助技术仍能读到完整数据。
- 数字区域使用固定宽度数字特性，避免计数过程中布局横向抖动。

### 无障碍

- 动态数字对辅助技术暴露最终完整文本，不逐帧播报中间值。
- `prefers-reduced-motion: reduce` 下直接显示最终值，不执行计数动画。
- 页面隐藏或浏览器失焦时不持续消耗动画帧；恢复后直接或正常完成目标值。

## 全站滚动浮现

### 覆盖范围

- 首页：首屏下方的产品入口、WHY 803、研究体系、能力模块、每日研究、FAQ、CTA 与合规说明。
- 今日决策台、风控提醒、策略信号观察、IPO 专题、会员服务：页面标题和各主区块。
- 重复卡片或列表以容器为主，必要时对子项使用短错峰；不对表格每个单元格逐一动画。

### 排除范围

- 固定或粘性导航、产品状态栏。
- 弹窗、抽屉、支付状态、加载骨架、下拉选项等临时交互层。
- 首页轨道 Canvas 及现有微光、悬停、加载动画。

### 动效参数

- 初始：`opacity: 0`、向下偏移约 `28px`、轻微 `blur(7px)`。
- 完成：`opacity: 1`、`translateY(0)`、`blur(0)`。
- 时长约 `760ms`，缓动 `cubic-bezier(0.22, 1, 0.36, 1)`。
- 同组子项错峰约 `70ms`，最大延迟不超过 `280ms`。
- 触发阈值约 12%，视口底部预留约 8%，让内容在进入阅读区域前自然出现。
- 每个元素只播放一次；路由切换后新页面元素按新的生命周期重新注册。

### 技术方案

- 新建单一职责客户端组件 `MotionController`，使用一个 `IntersectionObserver` 管理带 `data-reveal` 的元素。
- 使用 `MutationObserver` 注册路由切换后新挂载的元素；已显示元素通过 `data-reveal-state="visible"` 保持可见。
- 首页成果数字由独立 `CountUpValue` 组件负责，使用 `requestAnimationFrame` 和纯函数缓动计算。
- 全站各页面只添加声明式 `data-reveal`、`data-reveal-group` 与延迟变量，不引入第三方动画库。
- 不支持 `IntersectionObserver` 的环境直接显示最终状态。

## 验收标准

- 首页四个成果数字从 0 平滑到 10、300+、2、1200，单位和 `+` 不跳动。
- 日期、价格、股票代码、风险分与 IPO 数字保持静态。
- 从首页向下滚动时，各主区块连续浮现；切换到五个产品页时，各主区块同样浮现。
- 滚回已展示内容不会再次隐藏或重播。
- 减少动态效果模式下，所有内容和最终数字立即可见。
- 无新增第三方动画依赖、无横向溢出、无浏览器控制台错误。
- 单元/源码测试、SSR 测试、lint、生产构建与本地浏览器验收通过。

## 非目标

- 不改动研究数据内容、会员流程或 IPO 信息。
- 不发布、不部署、不推送远端。
- 不复制 Sober 的源代码、素材或品牌视觉。
