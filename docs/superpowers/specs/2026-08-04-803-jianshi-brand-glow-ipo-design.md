# 803见势研究品牌、首页微光与 IPO 进度设计

日期：2026-08-04  
状态：已确认（用户授权按推荐方案执行，不再逐项询问）

## 目标

在不改变现有深色研究平台整体结构的前提下，完成三项视觉与信息架构调整：

1. 将全站品牌统一为“803见势研究”，并使用用户提供的蓝青色上升柱状图 Logo。
2. 为首页四个核心入口增加克制、缓慢流动的蓝青色微光背景，提升层次感与高级感。
3. 重构 IPO 专题的发行上市进度对比，使两家公司按上下两行对齐展示节点及日期，并移除“关键时间线”。

## 品牌方案

- 全站可见品牌名、页面元数据、浏览器标题、无障碍名称和相关测试统一由“803研究”改为“803见势研究”。
- 副标题“A 股数据与信息研究平台”保持不变。
- 从用户提供的 Logo 图片中提取蓝青色柱状图和箭头主体，去除外围深色底与多余留白，输出透明背景 PNG。
- 导航栏中 Logo 位于品牌名左侧，保持清晰但不过度抢占高度；移动端同步缩放。
- Logo 是品牌识别图形，不替换当前页面其他功能图标。

## 首页四卡微光方案

适用入口：今日决策台、风控提醒、策略信号观察、IPO 专题。

- 保留现有两行两列布局、标题、图标、摘要及跳转行为。
- 每张卡片内部增加独立的蓝青色径向微光层，光源位于卡片底部或侧下方。
- 微光以低透明度缓慢漂移，四张卡使用轻微错开的延迟与位置，避免机械同步。
- 卡片边框与背景继续使用现有深色体系；微光不得影响正文对比度。
- 鼠标悬停时，当前卡片局部光晕轻微增强并向卡片内容区产生有限位移，同时维持克制的金融研究气质。
- 使用 CSS 伪元素、径向渐变和关键帧实现，不引入视频、Canvas 或额外动画库。
- 在 `prefers-reduced-motion: reduce` 下停止漂移动画，仅保留静态低亮度光晕。
- 小屏设备降低光晕尺寸和强度，避免出现大面积亮斑。

## IPO 发行上市进度对比

- 标题仍为“发行上市进度对比”。
- 长鑫科技与宇树科技由左右双列改为上下两行。
- 两行共享六个等宽阶段列：受理、问询、上市委、注册、申购、上市。
- 同一阶段在两行中垂直严格对齐，便于横向比较推进速度。
- 每个节点显示阶段名和日期；日期格式采用 `MM.DD`，例如 `08.10`。
- 已发生节点显示具体日期；计划节点显示日期并附“计划”；尚无公开明确日期的节点显示“待定”。
- 公司名称、当前状态和进度摘要置于每行左侧信息区，节点轨道位于右侧。
- 桌面端完整展示两行；窄屏端保持公司信息固定在行首，节点区域允许横向滚动，避免压缩文字。
- 保留节点的已完成、当前、计划、待定视觉状态，但日期比状态文案更优先。
